# WiFi Site Survey Automation v1.1.0

This folder contains the **1.1.0 local workflow** for WiFi site survey processing and Ekahau parameter-vs-range analysis.

It includes two main scripts:

- `data_extraction.py` — extracts survey images and generates processed outputs
- `rvr_parameter_vs_range.py` — builds parameter-vs-range analysis, plots, tables, and zip exports

This version is intended to run locally in **VS Code** on Linux.

---

## Features

### 1. Data extraction workflow
`data_extraction.py` is used to:

- read survey report files from `docx_input/`
- extract heatmaps and scale images into `out/`
- process outputs and save results into `ss_results/`

### 2. Parameter vs range workflow
`rvr_parameter_vs_range.py` is used to:

- read Ekahau `.esx` and exported CSV files from `ekahau_inputs/`
- compute distance-based performance curves
- generate plots and summary tables
- export final outputs into a folder such as `rvr_throughput/`
- create `rvr_full_output.zip`

## Inputs

## `docx_input/`

Put survey report `.docx` files here for the extraction workflow.

Example:

```text
docx_input/
├── KVD21 February 2026 Survey with Mesh Extender Report.docx
├── TMO-G4AR February 2026 Survey with Mesh Extender Report.docx
└── ...
```

## `ekahau_inputs/`

Put Ekahau analysis files here for the range-vs-parameter workflow.

Typical files:

* 1 master floorplan `.esx`
* router survey `.esx` files
* Ekahau exported `*band_output.csv` files
* optional `site_geometry.json`

Example:

```text
ekahau_inputs/
├── Floorplan.esx
├── TMO-G4AR February 2026 Survey (No APs).esx
├── TMO-G5AR February 2026 Survey (No APs).esx
├── Sagemcom_throughput for Living Room on 2.4 GHz band_output.csv
├── Sagemcom_throughput for Living Room on 5 GHz band_output.csv
└── site_geometry.json
```

## How to run `data_extraction.py`

Use this script when you want to process survey report files.

### Before running

Place your `.docx` report files inside:

```text
docx_input/
```

### Run

```bash
python3 data_extraction.py
```

### Expected output

The script will typically:

* read report files from `docx_input/`
* extract images into `out/`
* generate processed results into `ss_results/`

---

## How to run `rvr_parameter_vs_range.py`

Use this script when you want to generate parameter-vs-range plots from Ekahau exports.

### Before running

Place the required files inside:

```text
ekahau_inputs/
```

### Configure the parameter

Inside `rvr_parameter_vs_range.py`, update the selected parameter if needed.

Example:

```python
PARAM_NAME = "Throughput"
```

You can change it to values such as:

* `"Throughput"`
* `"Data Rate"`
* `"SNR"`
* `"Signal Strength"`

### Run

```bash
python3 rvr_parameter_vs_range.py
```

### Expected output

The script will generate:

* aggregated tables
* summary CSV files
* comparison plots
* metadata files
* `rvr_full_output.zip`

## Troubleshooting

### `ModuleNotFoundError: No module named 'cv2'`

Install dependencies again:

```bash
pip install -r requirements.txt
```

### `tesseract is not installed`

Install it with:

```bash
sudo apt install tesseract-ocr
```

### No outputs are created

Check that:

* input files are inside the correct folder
* filenames match the expected format
* `.esx` and CSV files match the selected parameter
* required folders exist inside `1.1.0`

### Script cannot find inputs

Make sure you run the script from inside the `1.1.0` folder:

```bash
cd 1.1.0
python3 data_extraction.py
```

or

```bash
cd 1.1.0
python3 rvr_parameter_vs_range.py
```
